## What is DocReplacer?

**DocReplacer** is a client-side AI writing tool that converts natural language prompts into structured, OpenXML-compliant `.docx` files — directly inside your browser.

No login. No data stored. Just prompt → download.

It solves the friction of copying AI-generated text into Microsoft Word and manually fixing the layout. DocReplacer generates tables, bullet points, headings, and sections that are ready for professional use immediately.

## ✨ Key Features

- **⚡ Instant Docx Generation** — Prompt to `.docx` in seconds
- **🔒 100% Client-Side** — All processing happens in your browser, not on any server
